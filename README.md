# Jeu de course automobile — NSI

## Présentation

Jeu de course automobile en 2D développé en Python avec Pygame dans le cadre d'un projet de NSI en programmation orientée objet.

## Objectif

Le joueur doit conduire une voiture sur un circuit et terminer plusieurs tours en réalisant le meilleur temps possible.

## Fonctionnalités prévues

* Affichage d'un circuit vu du dessus
* Déplacement de la voiture au clavier
* Chronomètre
* Compteur de tours
* Écran de départ et écran de fin

## Technologies

* Python
* Pygame
* Visual Studio Code
* Git et GitHub
